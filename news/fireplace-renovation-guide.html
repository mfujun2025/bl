安装指南 2026-09-22

壁炉装修预留尺寸与施工要点：2026年装修前必看指南

很多业主装修时临时决定装壁炉，结果发现墙没留够、烟道没走、电源没布，要么装不了，要么大改返工。壁炉一定要在装修设计阶段就规划好，水电施工前确定位置和尺寸。本文详解三种壁炉的预留尺寸、施工要点和装修流程中的时间节点，帮您一次到位不返工。

一、先确定壁炉类型，再谈预留

不同类型的壁炉，预留要求完全不同。装修前先确定选哪种：

  • 燃木壁炉：需要烟道、炉膛空间、防火处理，预留要求最多
  • 燃气壁炉：需要燃气管道、烟道（或直排管）、电源，预留中等
  • 电壁炉：只需要电源，预留最简单，装修完也能装
关键原则：燃木和燃气壁炉必须在装修设计阶段就确定位置，水电施工前完成预留。电壁炉最灵活，装修完了也能加装。

二、燃木壁炉预留尺寸与施工要点

1. 炉膛预留尺寸

嵌入式燃木壁炉需要在墙体里预留炉膛空间，尺寸根据所选型号确定：

  • 常见炉膛宽度：60-90cm（小型60cm、中型70-80cm、大型90cm以上）
  • 常见炉膛高度：50-70cm
  • 常见炉膛深度：40-55cm
  • 预留余量：每边比壁炉本体大2-3cm（方便安装和散热）

独立式燃木壁炉不需要嵌墙，直接放在地面上，但需要预留放置空间：

  • 壁炉本体宽度：50-70cm
  • 壁炉本体深度：40-55cm
  • 前方操作空间：至少80cm（添柴、清理）

2. 烟道预留

烟道是燃木壁炉最关键的预留项目，必须在土建阶段完成：

  • 烟道内径：不小于150mm（6英寸），大功率壁炉建议200mm（8英寸）
  • 烟道材质：双层不锈钢保温烟囱（室内部分）或砖砌烟道（需内衬不锈钢管）
  • 烟道走向：尽量垂直，弯头不超过2个，每个弯头角度不超过45°
  • 烟囱高度：高出屋顶屋脊60cm以上，高出周围10米内最高建筑2米
  • 穿墙位置：预留穿墙孔，直径比烟道大50mm，用防火材料封堵
  • 烟道与可燃物距离：双层保温烟囱距木龙骨≥50mm，单层烟囱≥200mm

3. 电源预留

  • 带风机的燃木壁炉需要电源，在壁炉侧面或下方预留一个10A插座
  • 插座位置距壁炉边缘≥30cm，避免高温影响
  • 如果计划装温控器，预留温控器线（弱电线管）

4. 防火处理

  • 壁炉背面墙体：贴防火板（硅酸钙板）或砌耐火砖，厚度≥20mm
  • 壁炉两侧墙体：距壁炉边缘≥200mm范围内用不燃材料
  • 壁炉台面（壁炉台）：用石材、砖、金属等不燃材料，不可用木质
  • 地面防护：壁炉前方铺防火地垫（金属或石材），尺寸至少宽出炉膛两侧各30cm、前方50cm
  • 顶部空间：壁炉上方1.2米内不可有可燃物（窗帘、木质装饰、画框等）

5. 燃木壁炉完整预留清单

  • [ ] 炉膛位置和尺寸已确定（嵌入式）
  • [ ] 烟道走向已规划，穿墙/穿楼板孔已预留
  • [ ] 烟囱穿出屋顶位置已确定，防水处理方案已明确
  • [ ] 电源插座位置已预留
  • [ ] 壁炉背面和两侧防火处理已纳入施工方案
  • [ ] 壁炉台面材料已确定（不燃材料）
  • [ ] 地面防火地垫位置已预留
  • [ ] 壁炉前方80cm操作空间已保证

三、燃气壁炉预留尺寸与施工要点

1. 炉膛预留尺寸

  • 常见宽度：60-120cm（线性燃气壁炉可做到1.5米以上）
  • 常见高度：40-60cm
  • 常见深度：30-45cm（比燃木壁炉浅，因为不需要存灰）
  • 预留余量：每边大2cm

2. 燃气管道预留

  • 管道材质：镀锌钢管或不锈钢波纹管（不可用铝塑管）
  • 管道口径：DN15（4分管）即可，大功率壁炉用DN20
  • 管道位置：从燃气表后单独引一路到壁炉位置，不可与其他燃气具共用
  • 阀门位置：在壁炉下方或侧面预留燃气阀门，方便检修时关闭
  • 管道试压：燃气管道安装后必须做打压试验（0.1MPa保压30分钟不漏）
  • 燃气表容量：确认家用燃气表流量足够（一般2.5m³/h的表可带10kW壁炉）
注意：燃气管道必须由有资质的燃气公司或专业人员施工，业主和装修队不能私自改管。改管前需向燃气公司申请。

3. 排烟预留

燃气壁炉有两种排烟方式，预留要求不同：

  • 同轴直排（平衡式）：最常见，一根双层管同时进空气和排废气
    • 管径：通常80/125mm（内层80mm排气，外层125mm进气）
    • 穿墙孔：直径150mm
    • 可水平穿墙排放，最长水平距离3-5米（看型号）
    • 排气口距门窗≥30cm，距地面≥30cm
  • 烟道式（自然排烟）：通过烟道向上排放
    • 烟道内径≥120mm
    • 要求与燃木壁炉烟道类似，但温度较低，防火要求稍低

4. 电源预留

  • 燃气壁炉的点火器、风机、温控器都需要电
  • 在壁炉下方或侧面预留10A插座
  • 建议带开关的插座，方便长期不用时断电

5. 燃气壁炉完整预留清单

  • [ ] 炉膛位置和尺寸已确定
  • [ ] 燃气管道走向已规划，已向燃气公司申请改管
  • [ ] 燃气阀门位置已预留
  • [ ] 排烟方式已确定（同轴直排/烟道式），穿墙孔或烟道已预留
  • [ ] 电源插座已预留
  • [ ] 壁炉背面防火处理已纳入方案（燃气壁炉温度较低，防火要求比燃木低）

四、电壁炉预留尺寸与施工要点

电壁炉最简单，没有明火、不需要烟道、不需要燃气，只需要电源。

1. 尺寸预留

  • 嵌入式电壁炉：按所选型号预留，常见宽度60-150cm，高度40-60cm，深度15-25cm（电壁炉深度很浅）
  • 独立式电壁炉：直接放置，预留摆放空间即可
  • 预留余量：每边大1-2cm

2. 电源预留

  • 电壁炉功率通常1.5-2kW，用普通10A插座即可
  • 在壁炉后方或下方预留插座，隐藏电源线
  • 建议单独一路线，避免与其他大功率电器共用

3. 电壁炉优势

  • 装修完了也能装，不需要提前预留烟道和燃气
  • 嵌入式只需要在电视背景墙留个洞+插座
  • 独立式插电即用，搬家能带走

五、三种壁炉预留要求对比

  • 烟道：燃木必须 / 燃气需要（同轴管或烟道） / 电壁炉不需要
  • 燃气管道：燃木不需要 / 燃气必须 / 电壁炉不需要
  • 电源：燃木可选（带风机需要） / 燃气必须 / 电壁炉必须
  • 炉膛深度：燃木40-55cm / 燃气30-45cm / 电壁炉15-25cm
  • 防火要求：燃木最高 / 燃气中等 / 电壁炉最低
  • 装修阶段：燃木必须设计阶段定 / 燃气必须水电阶段定 / 电壁炉随时可装

六、装修流程中的时间节点

第1步：设计阶段（开工前）

  • 确定壁炉类型和型号（拿到具体尺寸图）
  • 确定壁炉安装位置
  • 规划烟道走向（燃木/燃气）
  • 规划燃气管道走向（燃气型）
  • 在设计图中标注预留尺寸和位置

第2步：土建/拆改阶段

  • 嵌入式壁炉：砌墙时预留炉膛空间
  • 燃木壁炉：预留烟道穿墙/穿楼板孔
  • 燃气壁炉：预留排烟穿墙孔
  • 注意承重墙不能随意开洞，需提前确认

第3步：水电施工阶段

  • 布置电源插座（所有类型）
  • 燃气管道施工（燃气型，需燃气公司上门）
  • 温控器线管预埋（如需要）
  • 烟道安装（燃木型，可与水电同步）

第4步：泥木施工阶段

  • 壁炉背面防火板/耐火砖施工
  • 壁炉台面（石材/砖）安装
  • 壁炉周围墙面装饰施工
  • 注意：壁炉本体先不装，等装饰完成后再装

第5步：安装阶段（油漆完工后）

  • 壁炉本体安装就位
  • 烟道连接和密封（燃木/燃气）
  • 燃气管道连接和试压（燃气型）
  • 电源接线
  • 调试运行
  • 安装壁炉台面和装饰罩

七、常见错误与避坑指南

  • 错误1：装修完了才想装燃木壁炉。燃木壁炉必须走烟道，装修完后无法走明管（不美观且不安全），只能砸墙返工。避坑：设计阶段就确定
  • 错误2：烟道弯头太多、太长。烟道抽力不足会导致排烟不畅、烟气倒灌。避坑：尽量垂直，弯头不超过2个
  • 错误3：烟囱高度不够。低于屋脊会导致风倒灌、排烟困难。避坑：高出屋脊60cm以上
  • 错误4：燃气管道用铝塑管或软管。铝塑管不能暗埋，软管有老化风险。避坑：用镀锌钢管或不锈钢波纹管，由燃气公司施工
  • 错误5：壁炉背面用木质材料。高温可能导致炭化甚至起火。避坑：用硅酸钙板、耐火砖等不燃材料
  • 错误6：电源插座留在壁炉正后方。安装后插座被挡住，无法插拔。避坑：留在侧面或下方，距边缘30cm
  • 错误7：嵌入式炉膛尺寸卡得太死。没有余量导致安装时塞不进去。避坑：每边留2-3cm余量
  • 错误8：壁炉上方装木质电视柜或挂画。高温烘烤可能导致变形、开裂。避坑：上方1.2米内不用可燃物，电视建议装在1.5米以上或用隔热板

八、总结

壁炉装修预留的核心原则：越早确定越好，燃木燃气必须设计阶段定，电壁炉随时可装。

如果您正在装修，建议按以下优先级决策：

  • 想要真实火焰体验、有条件走烟道 → 选燃木壁炉，设计阶段就定好位置和尺寸
  • 想要真实火焰、不想烧柴 → 选燃气壁炉，水电阶段前申请燃气改管
  • 装修快完了/租房/预算有限 → 选电壁炉，插电即用，零预留

拿到壁炉型号的尺寸图后，交给设计师和施工队长，确保每个预留位置都准确。装修过程中多和壁炉商家沟通，有不确定的地方及时问，避免返工。希望这份指南能帮您顺利装出心仪的壁炉。
